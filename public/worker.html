APPLICATION ANDROID

Badge de connexion employé

Téléchargez PromedPara Worker sur le téléphone qui sera associé au compte employé. Le badge se renouvelle automatiquement et fonctionne sans Internet après l’association.

Télécharger PromedPara Worker · APK
Association
Dans l’application, saisissez l’adresse locale du poste et le code temporaire fourni par le propriétaire. Le code expire en cinq minutes et ne peut servir qu’une fois.
Utilisation
Ouvrez le badge à l’écran, puis présentez-le au lecteur SUNLUX. Le compte employé ne peut réceptionner des produits que si le propriétaire active cette autorisation.

La clé du badge est chiffrée dans Android Keystore. Un téléphone perdu doit être immédiatement révoqué depuis Comptes équipe.

Le code change toutes les 30 secondes. L’acceptation est limitée à une utilisation par période.
