Les ventes et alertes viennent directement du poste de caisse, sur le Wi‑Fi de la boutique. La base de données reste sur le poste. Aucun compte cloud n’est utilisé.

Installation et première connexion

  1. Téléchargez l’APK sur le téléphone Android.
  2. Ouvrez le fichier. Si Android le demande, autorisez temporairement l’installation depuis le navigateur utilisé.
  3. Ouvrez PromedPara Owner et entrez l’adresse locale affichée ci-dessus.
  4. Connectez-vous avec un compte propriétaire, puis autorisez les notifications.
  5. Appuyez sur Démarrer la surveillance. Android garde une notification visible pendant la connexion locale.

L’app doit rester en surveillance et le poste doit rester allumé sur le réseau. Android peut suspendre une app selon les réglages d’économie de batterie; autorisez son activité en arrière-plan pour améliorer la réception.
