PromedPara - install guide for the Windows 7 till

Screen names are written in French exactly as you will see them: like this. Everything is done by double-clicking; you never type a command.

What this kit does. The till (ALPHATEAM-PC, Windows 7 32-bit, 2 GB) runs the cashier app and keeps the database. The Sunlux scanner reads a changing barcode on the worker's phone to open the till. Owners use an Android app. All files, including the right 32-bit Node.js for Windows 7, are inside this folder, so no internet is needed on the till.

1Copy the kit to the till

  1. Plug the USB drive into the till. Copy the whole folder PromedPara-USB to the Windows Desktop (running from the desktop is faster and safer than from the USB).
  2. Open the copied folder. You should see 1-VERIFIER-LE-SYSTEME.bat, 2-INSTALLER.bat, and the folders app, runtime, android, tools.

2Check the till (changes nothing)

  1. Double-click 1-VERIFIER-LE-SYSTEME.bat. Wait about 30 seconds without touching anything.
  2. Read the result at the bottom:
    • PRET A INSTALLER - go to step 3. Yellow [ATTENTION] lines are advice, not blockers.
    • PROBLEME(S) A CORRIGER - each red [ ERREUR ] line says what to do. Fix it, run the check again.
  3. The check also starts the real server for a few seconds on a test port with a temporary database, so a green result means the program really runs on this PC.
  4. A report is saved as RAPPORT-VERIFICATION.txt in the folder. If anything stays red, take a photo of the screen or send that file.
The check looks atWhy it matters
Windows 7 SP1, free RAM / diskThe program needs Service Pack 1 and about 300 MB of disk.
Date and time (and drift vs internet)The phone badge changes every 30 s and is computed from the clock. Till and phone clocks must agree within 30 s.
Files intact (SHA-256 of every file)Detects a bad USB copy.
Node 12 + SQLite self-test and a real server startProves the engine runs on this exact machine.
Port 4173 freeAnother program using the port would block the till.
Chrome (or Firefox) versionThe cashier screen runs in the browser. Chrome 109 is the last version for Windows 7.
Xprinter driver, network addressReceipt printing, and the address the phones must use.

3Install

  1. Double-click 2-INSTALLER.bat. Click Oui when Windows asks for administrator rights.
  2. It runs the check again, then: copies the program to C:\PromedPara, opens the firewall for port 4173 for your local network only, creates two desktop shortcuts (PromedPara Caisse and Test lecteur code-barres). Check the Desktop: you should see the green star icon.
  3. PromedPara is a real desktop application (Electron, file C:\PromedPara\electron\PromedPara.exe), not a web link. It starts the local server by itself, opens its own window, and prints receipts directly on the default printer without a print window. Receipts need the Xprinter set as default printer.
  4. Backup plan: if the app ever refuses to open, double-click PromedPara (mode secours Chrome) inside C:\PromedPara. It opens the same cashier in Chrome.
  5. Three questions, answer O (oui) then Enter, unless you disagree:
    • start PromedPara automatically when the PC powers on (recommended: after a power cut the till is ready by itself);
    • stop Windows going to sleep while plugged in (recommended: a sleeping till cannot answer the phones);
    • launch PromedPara now.
  6. The database lives in C:\PromedPara\data. Re-running the installer later (for an update) never touches the data.

4Logins: one short code for everybody

Nobody types a username or a long password at the till. Each person has one personal code of 6 digits, tapped on the touch keypad of the login screen. The Sunlux also works on the same screen for phone badges.

LevelWho creates itWhat it can do
Admin (you)The very first screen, on the tillEverything an owner can, plus: create the owner, give an owner a new temporary code if forgotten, make a new recovery key.
OwnerThe adminStock, prices, suppliers, sales, workers and their codes. Cannot create owners.
WorkerOwner or adminSell. Optional rights switched on by the owner.
  1. Double-click PromedPara Caisse (green star icon on the Desktop).
  2. First screen: Créer le compte administrateur. Type your name, then your 6-digit code twice. Avoid 123456 or 111111 (refused).
  3. Then the recovery key appears, once: 16 characters like CNXS-F4FF-FUWF-3893. Write it on paper now and keep it away from the till. It is the way back in if you forget your code. Press J'ai noté la clé only when it is written.
  4. The owner's login: sign in as admin → Comptes équipe → Créer un compte → role Propriétaire. A temporary 6-digit code is shown once: give it to the owner. On first sign-in the owner is forced to choose his own code.
  5. Workers: the owner (or you) creates the account, then on the worker's card + Code PIN (step 7).
  6. Changing my code: Comptes équipe → my card → Changer mon code.

If a code is forgotten

Who forgotWhat to do
A workerThe owner opens the worker's card → Changer le code PIN (or leave empty to generate one).
The ownerThe admin opens the owner's card → Nouveau code temporaire. The owner picks a new code at the next sign-in.

Safety rules built in: the code login works only on the till itself, never from a phone over Wi-Fi. After 8 wrong codes in 10 minutes the keypad locks for 10 minutes and the owners are notified. After 5 wrong recovery keys, recovery locks for an hour.

5Test the Sunlux scanner on a phone screen (do this before anything else)

Why first: some 1D laser scanners cannot read a barcode shown on a phone screen at all. Better to find out now. If it fails, nothing is lost: workers can still log in with the one-time 8-digit code, and a scanner that reads screens is cheap.
  1. On the till, double-click the desktop shortcut Test lecteur code-barres. Touch the green field.
  2. On a phone connected to the shop Wi-Fi, open http://<till address>:4173/scanner-test.html. The till address is shown at the end of the check (for example http://192.168.1.20:4173).
  3. Scan the barcode on the phone with the Sunlux. Try the four bar sizes and full phone brightness.
  4. Success looks like: "Vitesse de lecteur détectée" and "Code correct". Then also try the button Faux badge qui change.
  5. If the Sunlux types characters but they are wrong (digits missing, other symbols): the scanner is set to a different keyboard layout or does not have Code 39 enabled; see the scanner's manual for "Code 39 enable".

6Bring in the product list from the old software (LOGICA)

  1. If the old list is not already exported: in LOGICA, export the list of articles to a CSV file (it is named like Articles_15-10-2026 22-35-00-touts-ar.csv). Put it on the Desktop, or on a USB drive.
  2. Sign in as owner and open Stock & produits. While the catalogue is empty, PromedPara looks for that file by itself (Desktop, Documents, Downloads, drive folders, USB drives) and shows a green banner Liste de l'ancien logiciel détectée. Touch Réviser et importer.
  3. If several candidates exist, you get a list (newest first) to pick from. The button Trouver le fichier ancien sur ce poste repeats the search at any time. If nothing is found, use Choisir un CSV à réviser and pick the file by hand.
  4. Check the column mapping (Article → name, Famille → category, PRIX_A → purchase price, PRIX_V → sale price, Qté → quantity, Alert → threshold). Nothing is written until you tick the confirmation and press Confirmer l'ajout. Duplicates are skipped, existing products are never overwritten.
  5. The old export has no barcodes. Add them product by product: Stock & produits → Modifier → touch the barcode field and scan the box with the Sunlux.

7Create a worker and pair the phone

  1. Owner (or admin): Comptes équipe → Créer un compte → role Employé, leave the password empty.
  2. On that worker's card touch Associer un téléphone. A 12-character code appears (valid 5 minutes, once) with the till address and the app download link.
  3. On the worker's Android phone (same Wi-Fi): open the download link, install PromedPara Worker (allow "install from this source" if Android asks), enter the till address and the code.
  4. The phone now shows a barcode that changes every 30 seconds.
  5. At the till: login screen → tab Employé → scan the phone barcode with the Sunlux. A barcode works only once; a screenshot of it is useless.
  6. Short code (PIN) instead of the phone: on the worker's card touch + Code PIN. Type 6 digits, or leave it empty to generate one (shown once, write it down and tell the worker). At the till the worker just taps the 6 digits on the touch keypad of the login screen. The pad also accepts the Sunlux, so badges and PINs both work on the same screen.
    • The PIN works only on the till itself, never from a phone over Wi-Fi.
    • Each PIN is unique; simple ones like 123456 or 111111 are refused.
    • After 8 wrong tries in 10 minutes the keypad locks for 10 minutes and you get a notification.
    • A PIN is easier to watch over a shoulder than a changing badge, so use the badge for workers you trust less. Retirer le PIN removes it.
  7. Lost phone: Révoquer on the card. Phone dead or scan failing: Code de secours gives an 8-digit one-time code that the worker types on the touch keypad.

8Let a worker add products, only when needed

On the worker's card in Comptes équipe there are two switches:

  • Peut réceptionner les livraisons - adds delivered quantities to existing products (no time limit, until you switch it off).
  • Peut ajouter des produits (8 h) - the worker gets a Nouveau produit screen to create new products. It expires by itself after 8 hours, you can switch it off any time, and you get a notification saying who added what. Workers can never edit or delete existing products, change prices of existing products, import files, or see reports.

The worker must sign in again after you switch it on, so the screen appears.

9Owner phone: notifications

  1. On an owner's Android phone (same Wi-Fi as the till), open http://<till address>:4173/owner-app and install PromedPara Owner.
  2. Enter the till address, sign in with the owner account, allow notifications, touch Démarrer la surveillance.
  3. You get an alert for each sale, delivery received, product added, low-stock threshold crossed, and security events (new badge, recovery code).
Honest limit: this version has no cloud. The alerts reach the phone only while the phone is on the shop Wi-Fi and the till is on. When an owner is away from the shop, nothing arrives; missed alerts are shown when the phone reconnects. Alerts away from the shop need an internet relay, which can be added as a next step (it would send sale information through an outside service, so it is your decision).

10Printer, cash drawer, customer display

  • Xprinter: install its Windows driver, set the paper width (58 or 80 mm) in the printer properties, and make it the default printer. The launcher then prints receipts directly with no dialog. If the receipt layout is off, change the paper width.
  • Cash drawer: it is not opened by the software yet. If its cable goes into the Xprinter (RJ11/RJ12), it can usually be opened by the printer; that needs its model and a test, so it is not guessed here.
  • Red customer display: not connected to the software yet; same reason (model and protocol unknown).

11Every day

  • Open: power on the till; PromedPara starts alone (if you chose that). Otherwise double-click PromedPara Caisse.
  • Worker: scans the badge, sells. At the end, Déconnexion.
  • Power cut: sales are written to disk within a quarter of a second, so at worst the sale being typed is lost. Just power on again.
  • Backups: automatic daily copy in C:\PromedPara\data\backups (last 30 days). Once a week double-click SAUVEGARDER-LES-DONNEES.bat (in C:\PromedPara) with a USB drive plugged in: it copies the database to the Desktop and to the USB. Keep that USB away from the till.
  • Stop the server: ARRETER-LA-CAISSE.bat (rarely needed).

12Automatic updates from GitHub (with backup versions)

Updates are published by you on a free public GitHub repository. The till checks it every 6 hours, downloads a small signed package (about 3 MB), and installs it between 03:00 and 05:00, at the next start, or right away when an owner presses Installer maintenant (Matériel → Mises à jour).

Why it is safe

  • Every update is signed with a private key that only you have. The till refuses anything not signed by it, even if someone took over your GitHub account.
  • Before installing, the till copies the database. The sales, products and accounts are never part of an update.
  • The previous 3 versions are kept on the till. Matériel → Versions de secours → Revenir à cette version goes back in about 30 seconds.
  • If a new version does not start correctly within 90 seconds, the till goes back to the working version by itself and never retries that broken version.
  • Old versions also stay on GitHub (Releases), so you can always publish an older one again.
Already done for this kit: the updates come from github.com/Virus-101/Promed-Para (public, Releases section). It is built into the kit, so the till needs no setup. The steps below explain how it was created and how to change it.

One-time setup: create the GitHub repository

  1. On any PC, open github.com. Click Sign up (free) and create an account, or sign in. Use an email you control and enable two-factor login.
  2. Click + (top right) → New repository.
  3. Repository name: promedpara-updates. Visibility: Public (this is required so the till can download without a password). Tick Add a README file. Click Create repository.
  4. Write down the full name shown at the top: youraccount/promedpara-updates. Nothing private goes in there: only update packages. Never upload sales data, and never your private signing key.
  5. On the till, in C:\PromedPara, double-click CONFIGURER-LES-MISES-A-JOUR.bat (answer Oui) and type youraccount/promedpara-updates.

To publish an update (every time)

  1. I build the release on my side with the private key and give you a folder with 3 files: latest.json, latest.json.sig and update-X.Y.Z.ppk.
  2. On GitHub open your repository → right side Releases → Create a new release.
  3. Choose a tag: type vX.Y.Z (same number, e.g. v2.1.1) and choose Create new tag. Title: the same. Drag the 3 files into Attach binaries. Keep Set as the latest release ticked. Click Publish release.
  4. Within 6 hours the till finds it. To test right away: Matériel → Vérifier maintenant.
  5. Never delete old releases: they are your backup versions.
Keep your private signing key safe. It is the file update-private.pem in the folder PromedPara-keys in the Windows user folder of the PC where updates are built. Put a copy on a USB drive stored away from the till and from this kit. If it is lost, the till can no longer accept updates (you would reinstall once from the USB with a new key). If someone else gets it, they could publish updates that tills would accept: tell me immediately.

Updates work only in the Electron app. The Chrome backup mode and the Windows 7 runtime itself (Node, Electron) are not updated automatically; those changes come by USB.

If something goes wrong

Get the errors in one click: double-click 3-COLLECTER-LES-ERREURS.bat (with the USB drive plugged in). It gathers the check report, install log, server log, firewall, printers and Windows errors into one file ERREURS-PromedPara-....txt, saved on the Desktop and on the USB. Bring the USB back to the PC, or send the file.
SymptomWhat to do
Nothing opens after double-clicking the shortcutWait 20 s on a slow start. Then open C:\PromedPara\logs\serveur-erreurs.log and send it, or re-run 1-VERIFIER-LE-SYSTEME.bat.
Phones cannot connectPhone and till must be on the same Wi-Fi/router. Re-run the installer (it recreates the firewall rule). Test from the phone browser: http://<till address>:4173/api/status must show text.
"Badge non valide"Check clocks on till and phone (within 30 s; set both to automatic time). Wait for the next code and scan again. Otherwise use Code de secours.
Screen is slow or jerkyClose other programs and browser windows. The till has no graphics acceleration; the launcher already disables it for Chrome.
Wi-Fi network is classed "Public" in WindowsThe firewall rule already covers all profiles but only for the local subnet. Nothing to change.
Update to a newer kit laterCopy the new folder, run its 2-INSTALLER.bat. The data in C:\PromedPara\data stays.
Security reminders. Choose a strong owner password. Do not forward ports on the router (the app is meant for the shop network only). Use a Wi-Fi password the customers do not know. The phone-to-till link is plain HTTP on your own network.

Technical note: the kit bundles Node.js 12.22.12 (32-bit, the last line that runs on Windows 7) and a pure-JavaScript SQLite (sql.js), so nothing needs compiling or installing besides this kit.
